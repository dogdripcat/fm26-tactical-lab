About / Methodology
FM26 Tactical Lab은 FM26의 역할·전술 구조를 evidence 기반으로 분석하는 도구입니다. Connected는 좋은 전술을 뜻하지 않으며, Unknown은 나쁜 전술을 뜻하지 않습니다. 확보된 FM26 근거가 부족하면 Unknown은 정상적으로 반환될 수 있습니다.
현재 IP 분석을 지원합니다. OOP evidence는 확장 중이며 tactic score는 제공하지 않습니다.
Technical details
연결과 근거 상태는 현재 등록된 역할 behaviour, semantic 및 provenance 범위만 표시합니다.
